How a run flows through the platform, and what ADR 0021 changes

Three figures. The first is the system as it ships today, from ADR 0016 and the CONTEXT.md glossary. The second is the direction PR 280 records in ADR 0021. The third is the OpenShell correction the same PR makes. Nothing in the PR changes code; figures two and three describe decisions and corrected assumptions.

1. Today: Gateway CRD and direct Agent Sandbox

  • Gateway is a Konveyor CRD: one provider, one endpoint, one credential Secret, one model. An AgentRun picks a model by naming a Gateway, so the controller never interprets a model name.
  • Hub mints a scoped token at AgentRun create time and injects HUB_BASE_URL, APP_ID and the token into the CR. It does not launch or manage workloads.
  • The harness is the only process with push authority. The agent commits on a local checkout the harness prepared.
